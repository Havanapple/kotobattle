Kotobattle

–
Island crossing

Tap a prefecture and type a word. You can only take a prefecture that touches one you own, or is across a crossing from one. A new area needs a word starting with the current letter (in Random mode a letter is rolled when you open it). To steal, use a word that starts with the area's own letter and scores more points. Each word can only be used once.

A letter is rolled each time an unclaimed area is opened, and can be re-rolled in the dialog. The timer is only a cue for the game master. A word can still be entered after it runs out.
Letter pool: tap a letter to take it out of the roll, or put it back. Letters that have been used in a word come up less often.

Shiritori

Each word must start with the last letter of the previous word. Tap letters to blacklist them: if a word ends in a blacklisted letter, the next word starts with the letter before it (FOX becomes O if X is blacklisted).

A round is one turn for each team. A passed turn scores nothing. With Full board, the game ends once every prefecture is taken and the round has finished, so both teams get the same number of turns.

Bonus words

Bonus
The bonus counts as the word's score, so a bonus word has to be beaten on points. Halves are allowed (1.5, 2.5) and scores are rounded up. It applies to words entered from now on.
